# 📋 TaskFlow – Project Management Tool

TaskFlow is a full-stack project management and task tracking web application developed as part of the **CodeAlpha Full Stack Development Internship**.

The application helps users create projects, manage tasks, assign tasks to team members, track progress, set priorities and due dates, and communicate through task comments.

## 🚀 Features

- 🔐 User Registration and Login
- 📊 Project Dashboard
- 📁 Create and Manage Projects
- 📝 Create Tasks
- 👥 Assign Tasks to Team Members
- 🔄 Task Status Management
- 🎯 Task Priority Management
- 📅 Due Date Tracking
- ✏️ Edit Tasks
- 🗑️ Delete Tasks
- 💬 Task Comments
- 📈 Project Statistics
- 👥 Team Members
- 📱 Responsive User Interface

## 🛠️ Technologies Used

- **Python**
- **Django 6.1.1**
- **HTML5**
- **CSS3**
- **JavaScript**
- **SQLite**
- **Git & GitHub**
